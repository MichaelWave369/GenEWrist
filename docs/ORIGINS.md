This foundation honors four supplied documents:

1. **GEN.E.WRIST v2.0 — MASTER SPECIFICATION**. The Builder's Companion. Three outer identity panels (House Screen, Sovereign Weave, R.E.S.O.N.A.N.C.E.), six middle apps (Realm Atlas, Loom Market, Snake's Toolkit, JourneyLog, TribeWire, SIGL Designer), nine inner play/well-being apps. 2. **Genewrist v2 generation**. Aspirational smart-device control, maps, app marketplace, humor, rest and community features. Later text frames AetherLink as an in-universe fictional connection fabric. This repository does not claim real Bluetooth, vehicle, smart home or telemetry integration.
3. **v3 generation**. The fictional left wrist Gen.E.Wrist, right-arm Aether Engine, Optic Eyes and Threads garments form a complete Builder's Suite. These are architecture inspiration, not existing physical devices.
4. **PARALLAX ENGINEERING RFC**. RHC-144γ and rhythmic feedback/scheduling envelopes are separate draft engineering research ideas. They are not established physical laws or validated control technology, and this implementation does not use them to control hardware.

Legacy names are retained when part of canonical fiction. New product identity is Enter the Field / Φ369 Labs.

## Scope labels
**Interactive demo:** local application UI actually responds. **Informational:** shows genuine historical design description but has no executable application. **Planned:** concept only; explicitly unavailable. These labels are not interchangeable.

The source says Gen.E.Wrist remembers only what its user chooses to shape. Accordingly, this app stores optional settings/favorites locally; the SIGL canvas is not persisted or transmitted. There are no remote services, analytics or sensitive sensor functions.
